# Codebase rules

- This project is a Next.js application using Tailwind CSS and shadcn/ui.
- The UI follows a "brutalist" design style, heavily using thick black borders (`border-[3px] border-black`) and harsh, offset box shadows (`shadow-[4px_4px_0px_0px_rgba(0,0,0,1)]`).
- Components should be interactive but retain the bold styling.
